# Portfolio - Phase 1

Portfolio professionnel en français de Kim Ngoc Pham.

## Structure

- `index.html` : page d'accueil
- `a-propos.html` : parcours, formations et compétences
- `projets.html` : trois emplacements de projets à compléter en phase 2
- `assets/style.css` : design du site
- `assets/script.js` : menu mobile et animations légères

## Publication sur GitHub Pages

1. Ouvrir le repository GitHub du portfolio.
2. Cliquer sur **Add file**, puis **Upload files**.
3. Importer les trois fichiers HTML et le dossier `assets` à la racine du repository.
4. Cliquer sur **Commit changes**.
5. Dans **Settings > Pages**, choisir **Deploy from a branch**, puis `main` et `/(root)`.
6. Cliquer sur **Save**.

Le fichier `README.md` peut aussi être importé, mais il n'est pas nécessaire au fonctionnement du site.
